
# Hightower Bible Ministry
## GitHub Repository Organization Plan

### Purpose
Organize Hightower Bible Ministry website files
to support future Bible studies, discipleship
lessons, and ministry growth.

### Proposed Folder Structure

- bible-studies/
  - matthew/
  - mark/
  - luke/
  - john/
  - acts/
  - genesis/
  - psalms/
- discipleship/
- christian-living/
- biblical-doctrine/
- pdf-study-guides/
- images/
- docs/

### Website Protection Rules

1. Do not delete existing ministry files
   without verifying that they are no longer needed.
2. Preserve all working website links.
3. Keep index.html in the main directory.
4. Preserve the CNAME file and domain configuration.
5. Review each file before moving it.
6. Update navigation links when file locations change.
7. Test the live website after every group of changes.
8. Keep Google Analytics tracking in new HTML pages.

### Current Priorities

1. Preserve Matthew chapters 1-4.
2. Organize existing Bible study files.
3. Prepare for the Book of Acts.
4. Continue developing the four Gospels.
5. Maintain existing Practical Christian Living
   and Biblical Truths & Doctrine lessons.

### Ministry Mission

Grounded in Truth, Growing in Christ.

Our goal is to make biblical teaching accessible,
accurate, organized, and easy to understand.
